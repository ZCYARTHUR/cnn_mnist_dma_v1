# 架构、数值规则与接口协议

## 1. 计算路径

PC负责训练，不在FPGA上训练。A53负责DMA、参数加载、分类结果读取和测试。PL执行整个固定CNN：卷积、ReLU、最大池化、全连接。最终softmax不在PL执行；对于同一尺度下的logit，argmax已经可以得到类别。

网络的张量形状：

| 层 | 输入 | 输出 | 计算 |
|---|---|---|---|
| Conv | 1×28×28 INT8 | 4×26×26 INT32 | kernel3×3，stride1，padding0，带偏置 |
| Requantize + ReLU | 4×26×26 INT32 | 4×26×26 INT8 | 右移缩放、舍入、饱和到0..127 |
| MaxPool | 4×26×26 INT8 | 4×13×13 INT8 | kernel2×2，stride2 |
| FC | 676 INT8 | 10 INT32 | 每个类别676项点积，带偏置 |

总权重6,796字节，偏置14×4=56字节。每张图有效MAC数为`4×26×26×9 + 10×676 = 31,096`。若将乘法与加法分开计为两个操作，则是62,192 operations；报告吞吐时必须注明计数口径。

## 2. 13个RTL模块

| 模块 | 具体实现 |
|---|---|
| `cnn_accel_top` | 总线连接、两帧缓存所有权、模型有效位、自动启动 |
| `axi_lite_ctrl` | AW/W独立缓存、读写响应保持、只读状态、软件复位 |
| `axis_input_adapter` | 识别模型/图片包，检查长度、TKEEP、TLAST与像素范围 |
| `input_buffer` | 两个独立所有权的图像bank，32位写入、同步字读取后选字节 |
| `weight_buffer` | 每路一个权重副本，同步读取，为并行输出通道提供独立读地址 |
| `window_generator` | 根据池化位置、子像素与tap生成3×3窗口地址；不生成庞大im2col矩阵 |
| `mac_array` | LANES个有符号8×8乘法器，寄存16位乘积，提供DSP推断提示 |
| `accumulator` | 各lane的INT32偏置加载与跨tap累加 |
| `requantize` | INT32经过ReLU、右移舍入、饱和转INT8 |
| `activation_pool` | 为4个卷积通道分别保存2×2区域最大值 |
| `layer_scheduler` | Conv→Pool→FC有限状态机、张量地址与FC输出分组 |
| `axis_output_adapter` | 锁存整张结果，输出12字包，在TREADY拉低时保持数据 |
| `perf_counters` | 单帧计算周期、完成帧数、MAC更新周期、输入/输出暂停周期 |

窗口地址模块当前从整帧片上RAM读取，**不是三行流式缓存**。第一版选择这一方式以支持明确可验证的池化顺序；滑动窗口流水化是后续优化。输入通道目前固定为1，因此累加器还没有通用多输入通道循环，不能只更改输入通道数就直接运行更深CNN。

权重副本容量约为`6796×LANES`字节，实际BRAM消耗还取决于器件RAM宽深配置与综合。并行度加倍会增加权重存储成本；不能只看乘法器个数。

## 3. 缓冲调度

输入图像轮流写bank0、bank1。图像包全部合法并收到最后TLAST后才提交为pending。计算核心按顺序取pending bank；正在计算或已提交的bank不能被覆盖，前端通过TREADY反压阻止下一帧进入。

计算一张图时允许加载另一张。卷积和池化之间、池化与全连接之间不经过DDR。输出结果被适配器锁存后依次传出；本版在前一结果包发送完成后才启动下一张计算，因此没有额外的多结果队列。

模型只允许在没有计算、待处理图片或未发送结果时重载。模型包开始后先清model_valid，完整通过校验才重新置位。没有合法模型时图像包不被接收。

软件复位会丢弃未完成任务并清模型有效位；若DMA也在传输，必须协调复位DMA。裸机初始化先复位DMA再复位CNN。

## 4. 量化约定

原MNIST像素`p`为0..255，输入量化值为`qx=p>>1`，范围0..127。训练时使用`qx/128`。因此输入小数位为7，不能把0..255原图字节直接当作signed INT8送入。

本次训练模型使用以下2的幂比例：

| 参数 | 本次值 | 定义 |
|---|---:|---|
| 输入指数 | 7 | `real_x = qx / 2^7` |
| 卷积权重指数 | 6 | `real_w ≈ qw / 2^6` |
| 池化特征指数 | 5 | `real_a ≈ qa / 2^5` |
| FC权重指数 | 6 | `real_fw ≈ qfw / 2^6` |
| 卷积右移 | 8 | `7 + 6 - 5` |

浮点权重导出使用NumPy nearest-even舍入到整数，再裁剪到[-127,127]。卷积偏置按`2^(7+wexp)`缩放，全连接偏置按`2^(aexp+fexp)`缩放，均以INT32传输。

卷积累加`z = qb + Σ(qx×qw)`。RTL的激活量化规则：

```text
z <= 0:            qa = 0
z > 0, shift = 0:  qa = min(z, 127)
z > 0, shift > 0:  qa = min((z + 2^(shift-1)) >> shift, 127)
```

偏置累加和乘积是有符号的。中间舍入加法使用33位，避免INT32最大正数加半LSB时溢出。正数刚好半格时向上舍入；这与权重量化的nearest-even是两个不同步骤，不能混淆。因为负数先被ReLU清零，不需要负激活舍入分支。

FC输出保留INT32，十个类别使用共同尺度`2^(aexp+fexp)`。其argmax直接作为预测类别。相同最大值时软件选择最小类别索引。

导出器检查最坏累加范围；Python和C参考也检查溢出。RTL不提供INT32累加溢出中断，手工更改偏置或改网络规模时必须重新进行范围证明。

## 5. Stream包：全部32位、小端字节序

每个DMA SimpleTransfer对应一个包，TKEEP固定`1111`，只有最后一个word的TLAST为1。传输地址需对齐；裸机采用64字节对齐。

### MODEL：1715 words，6860 bytes

| Word偏移 | 数量 | 内容 |
|---|---:|---|
| 0 | 1 | `0x434E4E01` |
| 1 | 1 | 右移shift，合法0..24 |
| 2..1700 | 1699 | 6796个权重字节，每字4个INT8 |
| 1701..1704 | 4 | 卷积偏置，INT32 |
| 1705..1714 | 10 | FC偏置，INT32 |

权重先放36个卷积权重，顺序`[output_channel][kernel_y][kernel_x]`；然后放6760个FC权重，顺序`[class][feature_index]`。feature_index为`channel*169+y*13+x`，即CHW展开。

word中最低8位是地址最小的字节。负权重使用二补码，如-1对应`0xFF`。模型驻留PL，多张图之间不用重发。

### IMAGE：197 words，788 bytes

word0是`0x434E4E02`。剩下196words是784个0..127像素，按行优先排列，每字4像素。输入不是PNG/JPEG文件内容；必须先解码为28×28灰度像素并进行相同量化。

### RESULT：12 words，48 bytes

| Word偏移 | 内容 |
|---|---|
| 0 | `0x434E4E10` |
| 1 | 本张核心计算周期，UINT32 |
| 2..11 | 类别0..9的INT32 logit |

输出顺序与输入顺序一致，本版不附带可随机重排的frame_id。输出适配器在反压期间保持TVALID、TDATA、TKEEP、TLAST。

### 错误处理

未知包、TKEEP非全有效、TLAST过早/过晚、shift超范围、图片含128..255字节都会置error。没有及时TLAST时丢弃后续数据直到包尾，再接受新包。error是sticky，只有复位清除；合法的下一包仍可解析，测试台验证恢复行为。正式应用发现error会停止并要求重新初始化。

## 6. AXI4-Lite寄存器

基地址`0x80000000`。32位读写，不需要通过控制寄存器逐像素搬运。

| 字节偏移 | 读 | 写 |
|---|---|---|
| `0x00` | ID=`0x434E4E31` | bit0写1软件复位，WSTRB[0]需有效 |
| `0x04` | 状态 | 不支持，SLVERR |
| `0x08` | 已完成帧数 | 不支持 |
| `0x0C` | 最近一帧核心周期 | 不支持 |
| `0x10` | 累计MAC更新周期 | 不支持 |
| `0x14` | 累计输入TVALID且非TREADY周期 | 不支持 |
| `0x18` | 累计输出TVALID且非TREADY周期 | 不支持 |
| `0x1C` | LANES：4、8或16 | 不支持 |

状态位：bit0=model_valid；bit1=busy；bit2=error；bits4:3=pending bank bitmap；bits8:5=调度状态。状态编码：0空闲、1偏置初始化、2RAM读取、3乘法、4累加、5存结果、6写池化特征。

未对齐或超过0x1C的读返回SLVERR。32位计数器可能回绕；100MHz下连续忙周期约42.95秒回绕，长测试应分段或使用差值处理。MAC更新周期是“累加器更新了多少个时钟”，不是有效MAC操作总数，不能直接当作GOPS分子。
